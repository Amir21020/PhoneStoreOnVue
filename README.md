# SneakerStore

Интернет-магазин кроссовок на Vue 3 с использованием Vite.

## Функционал

- Каталог товаров с поиском и сортировкой
- Добавление товаров в корзину
- Избранное (закладки)
- Оформление заказа
- Сохранение корзины в localStorage

## Технологии

- Vue 3 (Composition API)
- Vite
- Vue Router
- Axios
- Tailwind CSS
- @formkit/auto-animate

## Установка

```sh
npm install
```

## Разработка

```sh
npm run dev
```

## Сборка

```sh
npm run build
```

## Линтинг

```sh
npm run lint
```

## Структура проекта

```
src/
├── components/     # Компоненты (Card, CartItem, Drawer, Header и др.)
├── pages/          # Страницы (Home, Favorites)
├── App.vue         # Корневой компонент
└── main.js         # Точка входа
```
